# DSY1105 --- Desarrollo de Aplicaciones Móviles

Repositorio oficial de clases de código de la asignatura **DSY1105
Desarrollo de Aplicaciones Móviles**.

## Sobre la asignatura

Desarrollo de Aplicaciones Móviles es una asignatura orientada a
aprender, de manera práctica y progresiva, a construir aplicaciones
móviles funcionales.

Durante el semestre comenzaremos trabajando los fundamentos de
programación con **Kotlin** y avanzaremos gradualmente hacia el
desarrollo de aplicaciones Android completas utilizando **Android
Studio** y **Jetpack Compose**.

El objetivo es que cada estudiante comprenda no solamente cómo escribir
código, sino también cómo organizar una aplicación, construir
interfaces, manejar información, conectar servicios y preparar una
aplicación para su distribución.

## ¿Qué aprenderemos?

El recorrido de la asignatura se divide en tres grandes etapas.

### 1. Fundamentos de Kotlin

Comenzaremos desarrollando las bases necesarias para programar
aplicaciones móviles:

-   Variables y tipos de datos.
-   Operadores.
-   Estructuras de control.
-   Funciones.
-   Colecciones.
-   Programación Orientada a Objetos.
-   Manejo de errores.
-   Corrutinas.
-   Introducción a Android Studio.

Esta etapa permitirá construir una base sólida antes de comenzar el
desarrollo visual de aplicaciones Android.

### 2. Construcción de aplicaciones Android

Luego llevaremos los conocimientos de Kotlin al desarrollo móvil con
**Android Studio y Jetpack Compose**.

Trabajaremos con:

-   Componentes visuales.
-   Material Design.
-   Diseño y estructura de pantallas.
-   Navegación entre pantallas.
-   Formularios y validaciones.
-   Gestión de estado.
-   ViewModel.
-   Arquitectura MVVM.
-   Animaciones.
-   Persistencia local.
-   DataStore.
-   Room y SQLite.
-   Recursos nativos del dispositivo.

El objetivo será comenzar a construir aplicaciones organizadas,
mantenibles y centradas en la experiencia del usuario.

### 3. Integración y aplicación móvil completa

En la última etapa integraremos los componentes necesarios para
transformar una aplicación local en una solución móvil completa.

Trabajaremos con:

-   Consumo de APIs REST.
-   Retrofit.
-   Integración entre frontend móvil y backend.
-   Microservicios.
-   Patrón Repository.
-   Pruebas unitarias.
-   Aseguramiento de calidad.
-   Generación de APK.
-   Firma digital de aplicaciones.
-   Documentación técnica.
-   Preparación de la aplicación para distribución.

## Proyecto final

El semestre tendrá como eje el desarrollo progresivo de una **aplicación
móvil funcional**.

El **proyecto final estará basado en un proyecto real**, buscando que
los estudiantes enfrenten una problemática concreta y desarrollen una
solución móvil aplicando los conocimientos adquiridos durante la
asignatura.

El proyecto irá creciendo durante el semestre: desde el diseño y
construcción de sus primeras pantallas hasta la integración de
persistencia, recursos del dispositivo, servicios externos, backend,
pruebas y generación de una versión final de la aplicación.

La meta es finalizar la asignatura con una solución que se acerque a un
flujo de desarrollo profesional y que permita demostrar de forma
práctica las competencias adquiridas.

## ¿Para qué existe este repositorio?

Este repositorio será utilizado como **repositorio oficial de código de
la asignatura**.

Aquí se publicarán progresivamente los proyectos y ejemplos
desarrollados durante las clases para que los estudiantes puedan:

-   Revisar el código trabajado en cada sesión.
-   Repasar conceptos vistos en clases.
-   Comparar sus implementaciones.
-   Recuperar ejemplos cuando necesiten practicar.
-   Revisar la evolución de los proyectos.
-   Utilizar los ejemplos como material de apoyo para su aprendizaje.

El repositorio **no reemplaza el trabajo realizado en clases**. La idea
es que cada estudiante programe, pruebe, modifique y comprenda el código
durante las sesiones.

## Organización del repositorio

La estructura podrá crecer durante el semestre siguiendo una
organización similar a:

``` text
DSY1105-Desarrollo-Aplicaciones-Moviles/
│
├── clase-01/
├── clase-02/
├── clase-03/
├── ...
│
├── desafios/
│
└── README.md
```

Cada carpeta de clase podrá contener el código desarrollado durante esa
sesión y los recursos necesarios para ejecutarlo.

## Metodología de trabajo

Las clases tendrán un enfoque principalmente práctico.

La dinámica general será:

**Concepto → explicación → ejemplo → programación paso a paso → desafío
→ aplicación al proyecto**

El objetivo es avanzar desde ejercicios pequeños y comprensibles hacia
aplicaciones móviles cada vez más completas.

## Resultado esperado

Al finalizar la asignatura, los estudiantes deberán ser capaces de
desarrollar una aplicación móvil funcional, estructurada y conectada a
servicios externos, aplicando buenas prácticas de programación,
arquitectura, diseño de interfaces, persistencia, testing y control de
versiones.
